# Base64 编解码工具

一个纯前端的 Base64 在线编解码小工具，打开网页即可使用，无需安装、无需联网、没有任何后端服务。

## 功能

- **编码**：把任意文本（支持中文等 UTF-8 字符）编码为 Base64 字符串
- **解码**：把 Base64 字符串还原为原文；输入不合法时会给出明确提示
- **交换**：一键把输出回填到输入，方便连续编解码
- **复制**：一键复制输出结果
- 输入/输出实时字数统计

## 使用方式

直接用浏览器打开 `index.html` 即可。所有计算都在浏览器本地完成，输入内容不会发送到任何服务器。

## 技术说明

- 单文件实现：HTML + CSS + JavaScript，无框架、无构建步骤
- 编码使用 `TextEncoder` 先把文本转成 UTF-8 字节，再做 Base64，避免中文乱码
- 解码使用带 `fatal` 校验的 `TextDecoder`，非 UTF-8 内容会报错而不是输出乱码；同时兼容 URL Safe Base64（`-`、`_` 字符）
